# Vibe Coding Ideas

This is my personal repository of projects and experiments coded with Claude/AI assistance.

## Projects

### [Image Telephone](./image-telephone/)
An iterative AI image generation tool that works like a creative game of telephone. Start with a prompt, watch AI draw it in a playful GarticPhone style, describe what it drew, then draw again based on that description. It's creative telephone meets Pictionary with robots!

### [Property Hunter - Rastreador de Imóveis](./property-hunter-extension/)
A Chrome extension for real estate hunters in Brazil! Automatically extracts property data from major Brazilian real estate websites (ZAP Imóveis, Viva Real, Imovelweb, OLX, QuintoAndar, Loft) and saves it to Google Sheets with one click. Features a beautiful, playful UI with duplicate detection, offline queuing, and full Brazilian locale support (BRL currency, CEP, Brazilian states).
