# Vibe Coding Ideas

This is my personal repository of projects and experiments coded with Claude/AI assistance.

## Projects

### [Image Telephone](./image-telephone/)
An iterative AI image generation tool that works like a creative game of telephone. Start with a prompt, watch AI draw it in a playful GarticPhone style, describe what it drew, then draw again based on that description. It's creative telephone meets Pictionary with robots!
